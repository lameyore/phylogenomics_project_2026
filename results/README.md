# Results

## Preliminary findings

The preliminary analysis of *Carnobacterium* sp. MAG 17681 produced the following results:

- Genome completeness: 91.4%.
- Genome contamination: 1.2%.
- Assembly fragmentation: 496 contigs.
- ANI to *Carnobacterium pleistocenium* FTR1ᵀ: approximately 94%.
- Phylogenetic analysis places MAG 17681 close to *C. pleistocenium* FTR1ᵀ.
- Bootstrap support for the split separating this pair from the other sampled *Carnobacterium* taxa: 100.
