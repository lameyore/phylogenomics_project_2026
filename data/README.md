# Data description

## Study sample

The focal genome, *Carnobacterium* sp. MAG 17681, was reconstructed from the stomach metagenome of a Pleistocene wolf estimated to be approximately 45,000 years old.

## Genome assembly

- **Genome identifier:** MAG 17681
- **Assembly type:** Metagenome-assembled genome (MAG)
- **Number of contigs:** 496
- **Estimated completeness:** 86.4%
- **Estimated contamination:** 0.5%

## Comparative genomes

The comparative analysis includes *Carnobacterium pleistocenium* FTR1ᵀ and other selected *Carnobacterium* genomes.

## Data availability

Large input files are not stored in this repository.
