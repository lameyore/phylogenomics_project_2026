# Methods

## Genome quality assessment

The focal genome was a metagenome-assembled genome designated MAG 17681, reconstructed from the stomach metagenome of a Pleistocene wolf approximately 45,000 years old.

The assembly consisted of 496 contigs, with an estimated completeness of 91.4% and contamination of 1.2%.

## Average nucleotide identity

Average nucleotide identity (ANI) was used to evaluate genomic similarity between MAG 17681 and *Carnobacterium pleistocenium* FTR1ᵀ.

The observed ANI was approximately 94%. This value is below the commonly used 95–96% reference range for bacterial species delineation and motivates further comparative genomic analysis.

## Preliminary phylogenetic analysis

A preliminary maximum-likelihood phylogenetic tree was inferred from five concatenated proteins. The resulting topology placed MAG 17681 close to *C. pleistocenium* FTR1ᵀ.

The split separating this pair from the other sampled *Carnobacterium* taxa had a bootstrap support value of 100.

## Ortholog-based phylogenomic analysis

OrthoFinder was used to identify orthologous gene families among the genomes included in the comparative analysis. A total of 504 single-copy orthologous families were identified.

Following ortholog identification, the corresponding protein sequences were aligned using MAFFT and trimmed using trimAl. The resulting alignments were concatenated into a supermatrix using AMAS.

A maximum-likelihood phylogenetic tree was then reconstructed from the concatenated alignment using IQ-TREE. The resulting tree was visualized and annotated using iTOL.

This ortholog-based phylogenomic analysis was designed to evaluate the evolutionary placement of MAG 17681 using a broader set of conserved genes than the preliminary five-protein analysis.

## Interpretation

The ANI comparison and preliminary phylogenetic analysis indicate a close relationship between MAG 17681 and *C. pleistocenium* FTR1ᵀ. The ANI value suggests genomic differentiation, but additional evidence is required before drawing species-level taxonomic conclusions.

The phylogenomic tree based on 504 single-copy orthologous families provides a broader framework for assessing the relationship between MAG 17681 and its closest relatives.
